# 희소 사용자 하드 네거티브 생성용 G2R 증강 손실 연구

## 연구 요약

협업 필터링은 사용자별 상호작용 기록이 적으면 개인 선호를 충분히 학습하기 어렵다. 그래프 생성적 적대 추천(Graph Generative Adversarial Recommendation, G2R)은 그래프 기반 추천기에서 사용자가 상호작용하지 않은 아이템을 학습용 음성 후보로 생성하는 모형이다. 음성 샘플은 사용자가 선호하지 않는 것으로 학습에 사용하는 후보 아이템이며, 희소 사용자에서 G2R 생성자가 인기 아이템에 편중될 수 있다는 가설을 검증한다. 본 연구는 예측 선호도는 높고 실제 상호작용은 없는 후보에 보상하는 생성자 증강 손실을 설계한다. 하드 네거티브는 선호 가능성은 높아 보이나 실제 상호작용은 없는 구분이 어려운 후보이며, 이를 학습에 사용해 희소 사용자의 상위 추천 후보를 더 정확히 구분하는지 검증한다.

## 1. 연구 배경

### 연구 주제

- 추천 시스템은 일부 소비 기록으로 미소비 아이템의 선호를 추정하나, 사용자-아이템 상호작용은 전체 후보 중 일부만 관측되어 희소성과 결측이 함께 발생함  
  - 미관측 아이템에는 실제 비선호와 미노출 잠재 선호가 함께 포함될 수 있음  

- 협업 필터링은 상호작용 행렬에 의존하므로 희소 사용자의 개인화된 선호와 사용자-아이템 결정 경계를 충분히 반영하기 어려움  
  - 그래프 협업 필터링에서는 희소 이분 그래프의 인기 편향이 표현 학습에서 증폭될 가능성이 있음  

- 본 연구는 희소 사용자 환경의 협업 필터링과 G2R 생성 음성 문제로 범위를 한정함  
  - 희소 사용자에서 생성자가 인기 아이템 중심의 쉬운 음성으로 편중된다는 점은 본 연구에서 확인할 문제 가설임  

### 연구 필요성

- 협업 필터링 기반 접근은 희소 상호작용에서 잠재 요인을 학습하지만, 사용자별 기록 부족과 미관측 후보의 false negative 문제를 함께 고려해야 함 [Liu et al., 2023]  

- 이어 생성적 적대 신경망 기반 접근은 정보성 음성 생성으로 추천기를 학습하나, 강한 음성 생성이 상호작용 기록에 의존하므로 극도 희소 환경의 성능 검증이 필요함 [Li et al., 2023]  

- 또한 그래프 기반 접근은 이웃 집계와 잠재 표현을 활용하나, 반복 집계가 인기 편향을 증폭할 수 있어 생성 음성의 인기 편중을 사전 진단해야 함 [Zhou et al., 2023]  

- 그러나 G2R 생성 음성이 희소 사용자별 결정 경계 주변에 위치하는지 확인되지 않았으며, 고예측 미관측 후보는 false negative일 수 있으므로 held-out 양성 선택 여부를 신뢰도 검증 신호로 활용해야 함  

## 2. 연구 목표

### 최종 목표

- 학습 분할의 관측 상호작용과 미관측 후보를 이용해 증강 손실 결합 G2R 학습 모형을 구축하고, 희소 사용자별 하드 네거티브 생성 결과와 추천 점수를 산출함  

### 세부 목표

- 학습 분할의 사용자별 상호작용 수로 희소 사용자를 구분하고, 그래프 오토인코더(Graph Autoencoder, GAE) 기반 초기 추천기가 산출한 후보별 예측 선호도 점수로 하드 네거티브 후보군을 구성함  

- 무상호작용 여부와 예측 선호도에 인기도 감쇠 및 후보 신뢰도 가중치를 결합하여, 인기 아이템보다 사용자별 고선호 후보를 우선 생성하도록 증강 손실을 설계함  

- 기준 G2R 대비 Recall@50, NDCG@50, 결정 경계 근접도 및 held-out 양성의 생성 음성 선택 비율을 측정하여 추천 성능과 false negative 위험을 검증함  

## 3. 연구 방법론

### 데이터 수집

- Daraz Bangladesh 플랫폼이 제공하는 BanglishRev 공개 사용자-상품 자료를 활용하며, 사용자 식별자·상품 식별자·고유 상호작용 기록을 이용한 암묵적 피드백 이분 그래프를 구성함  
  - 중복 제거 자료는 사용자 934,949명, 상품 128,494개, 고유 상호작용 267만 건, 행렬 밀도 0.0022%로 구성됨  

- 자료에 기록된 동일 사용자-상품의 반복 상호작용은 하나의 이진 양성 간선으로 집계하고, 상품 메타데이터와 기타 사용자 피드백은 본 연구의 입력에서 제외함  
  - 학습·검증·평가의 양성 정답도 동일한 이진 간선 규칙으로 구성함  

- 사용자별 상호작용을 사용자 단위 고정 비율로 학습·검증·평가 분할한 뒤, 학습 분할의 상호작용 수만으로 희소 사용자 기준을 산정함  
  - 미관측 쌍은 음성 후보로만 관리하며, 검증·평가 양성은 학습 그래프에서 제외함  

### 제안 방법

- 처리 순서는 희소 사용자 선별, GAE 기반 미관측 후보 점수 산출, 인기도·신뢰도를 반영한 보상 계산, 생성 분포 갱신과 음성 표본 추출, 생성 음성을 이용한 판별기·추천기 갱신으로 구성함  

- 전체 목적함수는 기존 G2R 생성자·판별자 손실과 증강 손실을 결합함  
  - 보상 설계는 선호도 단독, 선호도·인기도, 선호도·인기도·신뢰도의 3개 안으로 한정하고 증강 손실 가중치는 0.1, 0.5, 1.0에서 탐색함  

#### 모듈 1: 희소 사용자 및 후보 표현 모듈

- 입력과 출력의 정의  
  - 학습 분할 사용자-아이템 그래프와 관측 이력을 입력받아 희소 사용자 구간, 사용자·아이템 잠재 표현, 미관측 후보군 및 후보별 초기 예측 선호도 점수를 출력함

  - GAE를 학습 분할의 이진 간선으로 학습하고, 사용자-아이템 잠재 표현의 내적으로 초기 예측 선호도를 산출함  
  - 희소성 임계값은 학습 분할 사용자별 상호작용 수 분포의 하위 구간을 이용한 추정 기준으로 설정함  

- 채택 근거  
  - 희소 사용자의 기록 부족으로 사용자별 후보 공간과 선호 신호가 불충분한 미해결 지점을 대상으로 함  

#### 모듈 2: 선호 기반 증강 보상 모듈

- 입력과 출력의 정의  
  - 희소 사용자 잠재 표현, 미관측 후보, 초기 예측 선호도 점수 및 학습 분할 인기도를 입력받아 후보별 증강 보상과 하드 네거티브 생성 분포를 출력함  

- 핵심 메커니즘  
  - 보상은 정규화한 예측 선호도 보상, 로그 정규화한 학습 분할 아이템 상호작용 수의 인기도 감쇠, 후보 신뢰도 가중치를 곱하는 구조로 구성함  
  - 인기도 감쇠 강도는 감쇠 미적용, 중간 감쇠, 강한 감쇠의 3수준으로 탐색함  

- 채택 근거  
  - 생성자가 인기 아이템 중심의 쉬운 음성으로 편중될 수 있다는 문제 가설을 사용자별 보상 설계로 검증하는 미해결 지점을 대상으로 함  

#### 모듈 3: 신뢰도 제어 적대 학습 모듈

- 입력과 출력의 정의  
  - 증강 보상, 생성 음성, 관측 양성 및 판별기 예측값을 입력받아 학습된 생성자·판별기와 추천 점수를 출력함  
  - 기준 모형 대비 성능과 경계 효과 검증은 실험 및 평가 단계에서 수행함  

- 핵심 메커니즘  
  - 보정용 held-out 양성으로 확인된 후보는 생성 음성 후보에서 제외하고, 나머지 후보에는 신뢰도 가중치를 적용해 보상을 감쇠함  
  - 생성자 갱신 후 판별기와 추천기를 생성 음성 및 관측 양성으로 갱신하는 순서를 반복함  

- 채택 근거  
  - 고예측 미관측 후보를 하드 네거티브로 선택할 때 실제 선호 아이템을 음성으로 처리할 수 있는 false negative 위험을 통제해야 함  

### 실험 및 평가

- 희소 사용자 환경에서 상위 추천과 개인화된 사용자-아이템 결정 경계 학습 태스크를 수행하며, 학습에서 제외한 평가 양성을 정답으로 사용함  

- 비교 대상은 증강 손실·인기도 감쇠·신뢰도 제어를 모두 적용한 제안 모형, 해당 항이 없는 기본 G2R, 균일 음성 샘플링, 동적 하드 네거티브 샘플링으로 구분함  

- Recall@50과 NDCG@50를 희소 사용자 구간별로 측정하고, 판별기 점수와 판별 임계값의 절대 차이를 생성 음성의 결정 경계 근접도로 정의함  
  - 사용자별 평균 후 희소성 구간별 평균을 보고함  

- 증강 손실, 인기도 감쇠, 신뢰도 가중치 제거 실험을 수행하고, 생성 시점에 선택된 held-out 양성 수를 전체 생성 음성 수로 나눈 비율을 false negative 위험 대리 지표로 산출함  

## 4. 기대 효과 및 활용 방안

### 학술적 기여

- 희소 사용자별 상호작용 규모와 초기 예측 선호도를 결합하여, 개인화된 하드 네거티브 후보군을 구성하는 기준을 제시함  

- 무상호작용 여부, 예측 선호도, 아이템 인기도 및 후보 신뢰도를 결합하는 생성자 보상 항과 가중치 산정 규칙을 제시함  

- 희소성 구간별 추천 성능, 결정 경계 근접도, held-out 양성 선택 비율을 함께 비교하여 손실의 효과와 false negative 위험을 검증하는 평가 절차를 제시함  

### 실용적 활용 방안

- 상호작용 기록이 적은 사용자가 많은 서비스에서 개인화 추천 학습용 음성 샘플 생성 정책으로 활용함  

- 그래프 기반 추천기의 음성 샘플링 모듈에 보상 항을 결합하고, 인기 편중과 held-out 양성 선택 비율을 점검하는 운영 분석 기준으로 활용함

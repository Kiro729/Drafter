[수정 규칙]
- 분량 초과: 불릿을 삭제하지 말고 각 불릿의 표현을 압축해 목표 글자수(공백 제외) 안팎으로 맞춘다.
  같은 항목 안에서 줄인다. 다른 항목의 내용을 옮겨 오지 않는다.
- 분량 부족(경고): 근거 없는 사실·수치·기관명을 추가하지 않는다. 이미 본문에 있는 내용을
  더 구체적으로 풀어 쓰거나, 그대로 둔다.
- 불릿 초과: 관련된 불릿을 합쳐 지정 개수로 맞춘다. 정보는 하위 불릿으로 내려 보존한다.
- 불릿 부족(경고): 있는 내용을 나눌 수 있으면 나누고, 아니면 그대로 둔다.
- 모듈 구조: 모듈 {module_count}개 모두 상위 불릿을 정확히 '{module_labels_arrow}'
  {module_count}개만 둔다. 그 밖의 항목의 내용은 {module_count}개 항목 중 하나의 하위 불릿으로 합친다.
- 양식 밖 소제목: 삭제하고 내용은 지정 항목의 하위 불릿으로 합친다. 새 소제목을 만들지 않는다.
- 제목 자리표시자: 첫 줄이 '# 연구명' 처럼 양식의 이름이면 본문 내용에 맞는 실제 연구 제목으로 바꾼다.
  제목이 그 아래 줄에 따로 적혀 있으면 그 문장을 '# ' 뒤로 올리고 아래 줄은 지운다.
- 제목 아래 본문: 제목 줄과 '## 연구 요약' 사이에는 아무것도 두지 않는다.
- 제목 주석: '## 1. 연구 배경 — {chars[연구 배경]}자' 처럼 제목 뒤에 붙은 글자수·설명을 지우고 '## 1. 연구 배경' 만 남긴다.
- 양식 기호: '■', '●' 로 시작하는 줄은 작성양식의 기호를 베낀 것이다. '■ 이름' 은 '## 이름', '● 이름' 은 '### 이름'
  소제목으로 바꾸고 그 아래 불릿은 그대로 둔다. '1) 모듈 1: 이름' 은 '#### 모듈 1: 이름' 소제목으로 바꾼다.
- 카드 ID 인용: [A-06] 같은 카드 ID 표기는 삭제한다(문장은 유지). 학술 논문은 [Author et al., Year] 로만 인용한다.
- 금지 표현: 수량·조건을 명시하거나 그 표현을 뺀다.
- 종결어미: 연구 요약을 제외한 모든 불릿은 "~함", "~임", "~해야 함" 으로 끝낸다.
- 연구 요약: 불릿 없는 산문 1문단, "~한다/~이다" 평서문 {summary_sentences}문장
  (문제 정의 → 기존 한계 → 제안 → 검증 → 기대 결과).
- 인용 위치: {citation_allowed_in} 밖의 인용은 표기 [Author et al., Year] 만 삭제하고 문장은 그대로 둔다.
- 인용 반복: 같은 출처가 {citation_repeat_threshold}회 이상이면 초과분의 인용 표기만 삭제한다.
- 실재하지 않는 인용: 인용 표기를 삭제하고 그 문장의 주장 범위를 좁힌다. 새 논문을 만들어 넣지 않는다.
- 마크다운 강조(**, *), 인라인 수식, 그림 언급은 제거한다.
- 참고문헌 항목은 쓰지 않는다. 본문 인용을 기준으로 코드가 생성해 붙인다.
  기존 참고문헌 섹션이 있으면 그대로 두어도 된다(코드가 교체한다).

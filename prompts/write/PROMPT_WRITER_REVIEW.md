[수정 지침]
- 피드백 항목을 중요도 순으로 모두 반영한다.
- 섹션 제목과 순서를 바꾸지 않는다. 새 소제목을 만들지 않는다.
- 양식에 지정되지 않은 하위 항목이 있으면 삭제하거나 지정된 하위 불릿에
  합친다. 특히 제안 방법의 모듈 {module_count}개는 하위 불릿 {module_count}개
  ({module_labels_arrow})만 두고, {module_next_ordinal} 번째 항목을 남기지 않는다.
- 4. 기대 효과 및 활용 방안은 학술적 기여와 실용적 활용 방안 두 항목만 둔다 (양식에 지정된 항목).
  예상 위험과 대응, 한계, 향후 과제 항목이 남아 있으면 삭제한다.
- 데이터 수집의 출처 불릿은 데이터셋 이름, 제공 주체, 데이터 형태와 포함 항목,
  규모가 모두 드러나게 보강한다. 뭉뚱그린 표현이 있으면 구체화한다.
- 지적되지 않은 부분은 그대로 둔다. 전면 재작성하지 않는다.
- 인용을 만들어내지 않는다. 모든 인용은 위 학술 논문 카드에 실재하는
  논문이어야 한다. 근거를 찾을 수 없으면 주장의 범위를 좁힌다.
- [증거]에 없는 사실, 수치, 기관명, 연도를 새로 넣지 않는다.

[문체 — 개조식]
- [연구 요약]을 제외한 모든 항목은 불릿으로 작성한다. 산문 문단을 쓰지 않는다.
- 각 불릿은 "~함", "~임", "~해야 함"으로 종결한다.
  "~한다", "~이다", "~된다" 종결을 쓰지 않는다.
- 예외: [연구 요약]은 산문 1문단, "~한다"·"~이다" 종결의 평서문 {summary_sentences}문장으로 쓴다.
  배경 지식 없는 독자가 한 번 읽고 이해할 수 있게 쓰고, 전문 용어·수식·수치
  나열을 피한다. 요약이 불릿으로 되어 있으면 이번 수정에서 산문으로 바꾼다.
- 하위 불릿은 명사구로 끝낼 수 있다.
- 불릿 하나는 한 줄에서 두 줄 안에 끝낸다.
- "첫째", "둘째", "셋째"로 항목을 나열하지 않는다.

[논리 표현 — 아래 규칙이 문장 길이 규칙보다 우선함]
- 항목 간 논리 관계는 불릿 계층으로 표현한다. 상위 불릿에 주장을 두고,
  근거·부연·예시는 하위 불릿에 종속시킨다.
- 계층으로 표현되지 않는 관계는 불릿 문두에 접속 표현을 둔다.
  대조: "그러나", "반면" / 인과: "이에 따라", "따라서", "그 결과" /
  한정: "단", "다만"
- 사실만 병렬로 놓이는 불릿 묶음을 만들지 않는다. 특히 [연구 필요성]의
  기존 접근과 미해결 지점 사이, 미해결 지점과 그 원인 사이는 반드시 명시한다.
- 한 불릿에는 두 개 절까지 허용한다. 논리 관계를 드러내기 위해 필요하다면
  절을 이어 쓰는 것이 짧게 끊는 것보다 낫다.

[작성 원칙]
- 앞 섹션에서 이미 쓴 내용을 뒤 섹션에서 반복하지 않는다.
- 금지 표현: {forbidden_emphasis}.
- 금지 표현: {forbidden_vague}. 수량이나 조건을 명시할 수
  없으면 그 표현 자체를 뺀다.

[표기 규칙]
- 용어는 한글 표기를 기본으로 하고, 최초 1회만 원어를 괄호로 병기한 뒤
  한글로 고정한다. 한글과 원어를 번갈아 쓰지 않는다.
  예외: 평가 지표명, 데이터셋명, 모델 구조명은 원어를 유지한다.
- 약어는 최초 1회 원어 완전형 병기 후 약어만 사용한다.
- 인용은 {citation_allowed_in}의 기존 접근 계열별 유형화에서만 표기하고(계열당 1회),
  불릿 말미에 둔다.
  그 밖의 항목(연구명, 연구 요약, 연구 주제, 연구 목표, 데이터 수집,
  제안 방법과 모듈, 실험 및 평가, 기대 효과)에 남아 있는 인용은 이번 수정에서
  삭제한다. 삭제해도 문장 내용은 그대로 둔다.
- 인용 형식은 [Author et al., Year] 로 하고 연도를 반드시 포함한다.
- 학술 논문 카드(C-xx)만 인용한다. 블로그명·매체명·웹사이트명 인용은 삭제하고,
  해당 내용은 인용 없이 서술한다.
- 같은 출처를 문서 전체에서 {max_same_citation}회를 넘겨 반복하지 않는다.
- 수식을 본문에 인라인으로 넣지 않는다.
- 그림을 본문에서 언급하지 않는다. 그림 번호·캡션·파일 경로·이미지 삽입
  문법을 쓰지 않는다. 그림은 조판 단계에서 자동으로 삽입된다.
- 마크다운 강조(**, *)를 쓰지 않는다.
- 제목은 초안의 양식 제목(#, ##, ###, #### 모듈 N:)을 그대로 유지한다. ■, ● 기호나 "— {chars[연구 배경]}자" 같은 분량 표시를
  제목이나 본문에 쓰지 않는다. 카드 ID([A-06] 등)를 본문에 쓰지 않는다.
